04 / PATH PROPERTIES

Apple Music setup & what this prototype does
  1. Install BlackHole 2ch.
  2. Open Audio MIDI Setup → + → Create Multi-Output Device. Enable your speakers or wired headphones and BlackHole. Use the physical output as the primary clock; enable drift correction on BlackHole. Use matching sample rates.
  3. Select that Multi-Output Device as your Mac’s sound output, then play Apple Music. Detailed routing instructions.
  4. Click Find inputs, allow audio permission, choose BlackHole 2ch, and click Connect input. If asked, macOS microphone permission also covers virtual audio inputs. This app never monitors the input back to speakers.

Share audio is an alternate browser capture option. Choose an audio-capable source and enable audio sharing. If the browser supplies no audio track, use BlackHole. Use Chrome for the initial experiment. No audio is uploaded or recorded.

This version analyzes audio, renders nine effects, previews LED samples, and exports editable scenes. It does not discover or send data to WLED controllers. A local UDP bridge is the next step for DDP output. Later, ESP32 firmware can evaluate effects at LED coordinates using the same normalized paths. It will need an audio source: microphone, line-in hardware, or audio features sent from the Mac. Flashing this HTML alone will not make the ESP32 capture Mac audio.

Scenes contain effect settings and paths, not audio. Changes are saved in this browser automatically. Export scene makes a portable backup; Load scene restores one. Audio files play locally and can be paused or scrubbed using the player.
